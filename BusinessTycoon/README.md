# Бизнес Магнат (Unity, C#, Android)

Idle-кликер, симулятор бизнеса. Игра написана на C# под Unity 2022.3 LTS, платформа Android, портретная ориентация.

## Что есть в игре

| Вкладка | Механики |
|---|---|
| **Главная** | Кнопка-кликер «Заключить сделку», прокачка навыков переговоров (клик растёт и получает % от пассивного дохода), сводка империи, лента новостей, престиж «Новая жизнь» (репутация даёт +10% ко всему доходу навсегда), сохранение и сброс |
| **Бизнес** | 17 бизнесов в трёх категориях. **Добыча**: ферма, лесопилка, рудник, нефтяная вышка. **Производство** (цепочки): пекарня (зерно → хлеб), мебельная фабрика, металлургический завод (руда → сталь), НПЗ (нефть → топливо), завод электроники (сталь + нефть), автозавод (сталь + электроника + топливо). **Услуги**, которые приносят деньги напрямую: от киоска до технологической корпорации. Покупка ×1/×10/×100/MAX, удвоение производства на отметках 10/25/50/100…, улучшения, которые оплачиваются **деньгами + сырьём** |
| **Склад** | 10 ресурсов. Рыночные цены постоянно колеблются и реагируют на новости. Продажа 50% или всего запаса, автопродажа через торгового агента (−10%), расширение склада за деньги + сырьё |
| **Биржа** | 8 компаний с графиками цен (случайное блуждание, возврат к справедливой цене, новостные скачки), дивиденды, покупка и продажа с комиссией. **Опционы Call/Put** с ценой по Блэку–Шоулзу: выбор страйка и срока (1/5/15 мин), досрочное закрытие, автоисполнение на экспирации. Портфель с P/L |
| **Компании** | Можно основать до трёх собственных компаний в пяти отраслях: нанимать сотрудников, вкладываться в маркетинг и R&D (R&D оплачивается ещё и сырьём), провести **IPO** с продажей 10/25/49% и получить деньги. После IPO акции компании торгуются на бирже, а доход игрока пропорционален его доле. Частную компанию можно продать |
| **Банк** | Вклад под процент и кредит с лимитом в 50% капитала |

Дополнительно:
- Офлайн-прогресс до 8 часов с отчётом при возвращении.
- Автосохранение каждые 10 секунд и при сворачивании приложения.
- Кнопка «Назад» на Android возвращает на главную вкладку или сворачивает игру.

## Оформление

Стиль мобильных игровых окон: индиго-панели, тёмные утопленные ячейки, заголовки окон капсом, объёмные кнопки с тёмной «губой» (золотые для покупок, синие и зелёные для действий), белые круглые значки, активная вкладка зелёная. Палитра задана в `Assets/Scripts/UI/UIKit.cs` (класс `Pal`).

Весь интерфейс строится из кода (uGUI), без префабов. Сцена создаётся автоматически при сборке. Поэтому проект можно открыть в Unity и сразу запускать, ничего не настраивая вручную.

## Структура

```
BusinessTycoon/
├─ Assets/
│  ├─ Scripts/Core/      — логика без зависимостей от Unity (данные, состояние, экономика)
│  ├─ Scripts/Game/      — GameController: игровой цикл, сохранение, офлайн-доход
│  ├─ Scripts/UI/        — интерфейс: UIKit, UIRoot и экраны-вкладки
│  └─ Editor/BuildScript.cs — настройка Player Settings и сборка APK
├─ CoreTests/            — консольные тесты логики (запускаются без Unity)
├─ Packages/manifest.json
└─ ProjectSettings/ProjectVersion.txt
```

## Как запустить в Unity

1. Установите **Unity 2022.3 LTS** с модулем **Android Build Support** (через Unity Hub). Подойдёт и Unity 6: проект обновится при открытии.
2. Unity Hub → **Add project from disk** → выберите папку `BusinessTycoon`.
3. Меню **Tycoon → Setup Project**: создаст сцену и настроит проект.
4. Нажмите **Play**. Для удобства в окне Game выберите портретное разрешение, например 1080×1920.
5. Чтобы собрать APK: **Tycoon → Build Android APK**. Файл появится в `Builds/Android/BusinessTycoon.apk`.

## Сборка APK в GitHub Actions

Workflow `.github/workflows/unity-android.yml` сначала прогоняет тесты логики, затем собирает APK через [game-ci](https://game.ci).

Для сборки нужны секреты репозитория (**Settings → Secrets and variables → Actions**):
- `UNITY_EMAIL` и `UNITY_PASSWORD` — данные аккаунта Unity;
- `UNITY_LICENSE` — содержимое файла лицензии `.ulf`. Как получить его для бесплатной Personal-лицензии, описано на https://game.ci/docs/github/activation.

Готовый APK появится во вкладке **Actions** → нужный запуск → **Artifacts → BusinessTycoon-apk**. Скачайте его на телефон и установите (разрешите установку из неизвестных источников).

Если game-ci не найдёт образ для версии Unity из `ProjectSettings/ProjectVersion.txt`, укажите там другую доступную версию 2022.3.x.

## Тесты логики без Unity

```bash
cd BusinessTycoon/CoreTests
mcs -out:core-tests.exe CoreTests.cs ../Assets/Scripts/Core/*.cs
mono core-tests.exe
```

Тесты проверяют производство и склад, улучшения, биржу, опционы, IPO, банк и офлайн-доход. Отдельно бот проигрывает 4 часа игры, чтобы проверить баланс.
