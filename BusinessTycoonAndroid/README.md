# Бизнес Магнат — Android (.NET, C#)

Idle-кликер и симулятор бизнеса. Нативное Android-приложение на C# (.NET 10 for Android), APK собирается в GitHub Actions.

**Скачать последнюю сборку:** Releases → «Бизнес Магнат — последняя сборка» (`apk-latest`). Нужен Android 9 или новее.

## Игровая механика

- **Уровни.** Опыт даётся за заработок (1 XP за $50) и действия. Уровень открывает бизнесы, товары магазина, отрасли, формы компаний, вклады (ур. 2), акции (ур. 3), кредиты (ур. 5), опционы (ур. 8) и холдинг (ур. 28).
  С 15-го уровня для повышения нужны предметы из магазина: «Бизнес-курс» (уровни 16–20), «Сертификат ISO» (21–30), «Диплом MBA» (31–40), «Членство в клубе миллиардеров» (41–50), «Место в совете директоров» (51–60).
- **Бизнесы.** 17 точек: добыча сырья, производственные цепочки, услуги. Улучшения стоят денег и сырья, а выше 5-го уровня ещё и «Комплекты модернизации».
- **Магазин.** Ноутбуки, серверы, кассы, кухни, фуры, станки ЧПУ, электростанции, офисы, склады, банковская лицензия и предметы развития.
- **Свои фирмы.** 7 отраслей: IT, розница, общепит, логистика, производство, энергетика, банк.
  - Регистрация как ИП или ООО. Нужен стартовый набор оборудования; ООО дополнительно требует офис.
  - Каждому сотруднику нужно рабочее место: ноутбук, касса, кухня, фура, станок и т.д.
  - Выручка = min(мощность штата, спрос рынка). Маркетинг растит спрос, R&D — выработку, оборудование даёт бонус.
  - Из выручки платятся зарплаты, аренда и налоги: ИП — 6% с выручки, ООО и выше — 20% с прибыли. Убыток оплачивает владелец.
  - Путь развития: ИП → ООО → АО → ПАО (через IPO, акции торгуются на бирже) → Корпорация. Для каждого шага нужны уровень, штат, оценка компании, взнос и офис.
  - **Холдинг** (ур. 28, от 3 фирм, офис класса A): +5% выручки за каждую фирму и налог 15%.
- **Биржа.** 39 компаний в 6 секторах. Это вымышленные компании и пародии на известные бренды с изменёнными названиями. Есть дивиденды, опционы Call/Put и банк.

## Firebase: вход через Google, облачное сохранение, рейтинг

Без настройки игра работает офлайн, блок «Аккаунт» просто подсказывает, что облако не подключено.

1. Создайте проект на https://console.firebase.google.com.
2. **Authentication → Sign-in method → Google** → включить.
3. **Realtime Database → Create database**. Во вкладке **Rules** вставьте содержимое `database.rules.json` из этой папки и нажмите **Publish**.
4. **Project settings → Your apps → Add app → Android**:
   - Package name: `com.tycoongames.bizmagnat`
   - SHA-1 ключа, которым подписан APK. Он печатается в отчёте каждой сборки (Actions → запуск → Summary).
     Сейчас в репозитории заданы секреты `ANDROID_KEYSTORE_*`, и SHA-1 такой:
     `A9:E4:5F:19:76:99:C4:28:CA:48:D7:80:43:72:0D:06:B9:A2:68:1F`.
     Если секреты убрать, APK будет подписан dev-ключом: `D3:A0:FC:4D:5A:A1:C1:C6:FE:C8:F2:FB:0B:3D:44:1F:15:01:79:4B`
5. Скачайте `google-services.json` **после** создания базы, чтобы в нём был адрес базы. Дальше любой из двух вариантов:
   - положите файл в папку `BusinessTycoonAndroid/` и закоммитьте;
   - или создайте секрет репозитория `GOOGLE_SERVICES_JSON` с содержимым файла (**Settings → Secrets and variables → Actions**).
6. Запустите сборку (**Actions → Android APK (.NET) → Run workflow**) и установите новый APK.

В базе данные хранятся так:
- `users/{uid}/save` — сохранение игрока (читать и писать может только он сам);
- `leaderboard/{uid}` — имя, капитал и уровень для общего рейтинга.

### Про ключ подписи

`signing/dev.keystore` — ключ для разработки (пароль `bizmagnat-dev`). Он лежит в репозитории, чтобы SHA-1 не менялся от сборки к сборке. Для публикации в Google Play создайте свой ключ и задайте секреты:
- `ANDROID_KEYSTORE_BASE64` — keystore в base64;
- `ANDROID_KEYSTORE_PASSWORD` — пароль;
- `ANDROID_KEY_ALIAS` — alias.

После этого добавьте SHA-1 нового ключа в Firebase. Его можно взять в отчёте сборки: Actions → запуск → Summary.

## Структура

```
BusinessTycoonAndroid/
├─ Core/          — игровая логика без Android: данные, состояние, экономика, биржа, компании
├─ Tests/         — консольные тесты ядра (mono), запускаются в CI перед сборкой
├─ UI/            — интерфейс из кода: Ui (палитра, 3D-кнопки), Shell, экраны
├─ Cloud.cs       — Firebase: Google Sign-In (Credential Manager), Auth REST, Realtime Database REST
├─ SaveStore.cs   — локальное сохранение (JSON)
├─ MainActivity.cs
└─ signing/       — dev-ключ подписи
```

Тесты локально:

```bash
cd BusinessTycoonAndroid/Tests
mcs -out:core-tests.exe CoreTests.cs ../Core/*.cs && mono core-tests.exe
```
