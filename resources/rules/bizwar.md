# 1. Загальні положення

**1.1 Війна за бізнес — ігровий механізм змагання між сім'ями за право володіння впливом над бізнесом. Усі учасники зобов'язані дотримуватись цих правил протягом усього бою.**

**1.2 За дотриманням правил стежать адміністратори нелегального напрямку. Усі скарги розглядаються виключно ними у відповідному розділі Discord.**

**1.3 Адміністрація рекомендує фіксувати порушення на відео — це єдиний надійний доказ у спірних ситуаціях.**

**1.4 Якщо під час одного бізвару сім'я отримала три або більше зафіксованих порушень — адміністрація вилучає один бізнес цієї сім'ї.**
```diff
- [−1 бізнес]
```

**1.5 Якщо учасник сім'ї отримує бан за грубе порушення безпосередньо під час бізвару — результат бою анулюється, а сім'я порушника втрачає два бізнеси за їх наявності.**
```diff
- [Бан за порушення + втрата двох бізнесів]
```

**1.6 Якщо сім'я систематично ухиляється від захисту бізнесів — демонструє постійну відсутність мінімуму гравців онлайн протягом 7 днів поспіль — адміністрація має право конфіскувати її бізнеси.**
```diff
- [Адміністративна конфіскація бізнесів]
```

**1.7 Скарги на порушення правил бізвару подаються виключно у відповідному розділі Discord протягом 72 годин після завершення бою. Скарги без доказів або після закінчення терміну — не розглядаються.**

**1.8 Скарга має містити: назви обох сімей, дату та час бою, опис порушення з посиланням на пункт правил, відео або скріншоти як докази.**

**1.9 Адміністрація розглядає скарги протягом 24 годин та публікує вердикт у тому самому розділі.**

**1.10 Заборонено будь-яким чином перешкоджати учасникам сімей ініціювати захоплення бізнесу (забивати бізвар). До перешкоджання прирівнюється: вбивство, нанесення урону, блокування доступу до точки забиву або будь-які інші дії, які заважають гравцям розпочати війну за бізнес.**
```diff
- [Jail 60 хвилин + повернення бізнесу]
```

**1.11 У разі захоплення однією сім'єю 100% бізнесів на сервері, сім'я отримує 3 доби (72 години) на збір прибутку з усієї мапи. Після завершення цього терміну адміністрація проводить примусове обнулення кришування (всі бізнеси переходять у нейтральний статус) для відновлення конкуренції на сервері.**
```diff
! Примітка до п. 1.11: Протягом цього часу інші сім'ї мають право продовжувати атаки на бізнеси. Обнулення не впливає на загальну статистику перемог/поразок у поточному сезоні війн
```

**1.12 Сім'я має право взяти "мороз" (тимчасове звільнення від участі у війнах за бізнес) не більше 2-х разів на календарний тиждень. Максимальна тривалість одного морозу - 12 годин.**

**1.13 Інтервал між взяттям морозів для однієї сім'ї повинен становити не менше 48 годин.**

# 2. Поведінка під час бою

**2.1 Забороняється використовувати баги анімацій або стрільби проти гравців — збиви анімацій, прискорена стрільба, слайди, +C проти гравців та подібні технічні прийоми.**
```diff
- [Jail 60 хвилин + повернення бізнесу]
```

**2.2 Забороняється виходити з гри під час активного бою.**
```diff
- [Jail 30 хвилин]
```

**2.3 Забороняється переходити в AFK під час активного обстрілу або бою.**
```diff
- [Jail 30 хвилин]
```

**2.4 Забороняється навмисно уникати бою після отримання переваги по рахунку — ховатись, бігати по карті або затягувати час до завершення таймера.**
```diff
- [Jail 120 хвилин + технічна поразка]
```

**2.5 Забороняється антифраг — навмисне вбивство союзника або самогубство з метою не віддати фраг ворожій стороні.**
```diff
- [Jail 60 хвилин]
```

**2.6 Забороняється займати будь-які висотні позиції, що не належать до основного рівня землі зони бізвару.**
```diff
! Примітка до п. 2.6: Бій має проходити виключно в одній площині (на землі). Заборонено знаходитись на дахах, мостах, естакадах, будівельних кранах, контейнерах тощо, які знаходяться вище основної зони перестрілки. Якщо для заняття позиції потрібно використовувати обхідні шляхи по висоті або стрибки на об'єкти це вважається порушенням. Винятком є природні височини, газони та елементи наземного ландшафту.
- [Jail 30 хвилин + повернення бізнесу]
```

**2.7 Забороняється використання бронежилета під час бізвару.**
```diff
- [Jail 30 хвилин + повернення бізнесу]
```

**2.8 Забороняється використання маски під час бізвару.**
```diff
- [Jail 90 хвилин + повернення бізнесу]
```

**2.9 Забороняється зловживати ігровими механіками, що дають штучну перевагу над суперником — кайданки та інші подібні функції.**
```diff
- [Jail 60 хвилин]
```

**2.10 Забороняється використовувати чити, баги або стороннє програмне забезпечення, що надає перевагу в бою — аімбот, ESP, тригербот, макроси тощо.**
```diff
- [Jail 120 хвилин / Бан 30 днів + повернення бізнесу]
! Примітка до п. 2.10: За використання багів стрільби видається міра покарання - Jail 120 хвилин
```

**2.11 Забороняється змінювати файли гри, текстури або моделі з метою отримання технічної переваги в бою.**
```diff
! Примітка до п. 2.11: Дозволено використовувати timecyc для налаштування візуальних ефектів. Ці зміни не впливають на бойові механіки та є допустимими.
- [Бан 30 днів + повернення бізнесу]
```

**2.12 Заборонено використання нереалістичних моделей персонажів, а також будь-яких скінів, що надають технічну перевагу під час стрільби чи переміщення (зменшений або нестандартний хітбокс, ролики, карлики, жіночі скіни з неприродними пропорціями тощо)**
```diff
- [Jail 60 хвилин + анулювання війни за бізнес]
```

# 3. Маніпуляції зі складом

**3.1 Забороняється залишати сім'ю або виганяти учасників під час активного бізвару з метою уникнення смерті або зменшення рахунку фрагів.**
```diff
- [Jail 60 хвилин + повернення бізнесу]
```

**3.2 Забороняється створювати підставні сім'ї для накручування перемог через фіктивні бої з метою нечесного отримання бізнесів.**
```diff
! Примітка до п. 3.2: Ознаками підставної сім'ї можуть бути: існування менше 14 днів, менше 5 активних учасників, відсутність будь-якої іншої активності на сервері, підозріла серія результатів з однією конкретною сім'єю. Адміністрація проводить розслідування на підставі скарг.
- [Розформування фейкової сім'ї + Догана сім'ї, яка отримувала переваги + вилучення причетних бізнесів + Бан 15 днів лідеру та причетним гравцям]
```

**3.3 Забороняється зривати чужий бізвар — завдавати шкоди або вбивати гравців з метою перешкодити проведенню бізвару.**
```diff
- [Jail 60 хвилин + вилучення одного бізнесу]
```

**3.4 Забороняється навмисно вступати до сім'ї — з основного або додаткового акаунту — з метою зливу бізварів, передачі внутрішньої інформації ворожій стороні або будь-якого іншого навмисного завдання шкоди організації зсередини.**
```diff
- [Бан 14 днів + вилучення причетних бізнесів / Постійне блокування у разі повторення]
```
